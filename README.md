# Python Code Editor

Students write and run Python in the browser. The left side shows program output. The right side is the Python Code Editor. Starter code lives in the `Python Code Editor` folder and starts empty.

Python runs on the student's own computer with Pyodide. Nothing is sent to a server.

```bash
npm install
npm run dev
```

Open the local address Next prints. Type Python in the editor, then press Run.
